# the restart contract, so they carry no depth-case annotations.
#
# Dropped room objects do not survive a restart.
#
# C evidence: boot_db() re-reads the area files and runs reset_zone() for every
# zone (src/db.c:304-392), and nothing in the shutdown path writes world state
# (src/comm.c:288-293 saves the clan table, the whod file and the mud date, and
# closes the player file). A loft of bread on the floor of the temple therefore
# disappears. The Go port used to persist it in data/world_state.json; that
# invented snapshot was removed (RULEBOOK R4) — see
# docs/fidelity/audit-reports/world_state_persistence_audit.md.
#
# The same vehicle proves the other half of the boundary: the loaf the actor is
# still CARRYING comes back, because C rents a quitting immortal's gear
# (src/act.other.c do_quit -> Crash_rentsave) and the port stores carried objects
# with the character. Dropped is transient; carried is durable.

# (src/interpreter.c:2195-2199). Quitting anywhere else would exercise
# DP-1310's still-open load-room path (docs/fidelity/depth/save.tsv).

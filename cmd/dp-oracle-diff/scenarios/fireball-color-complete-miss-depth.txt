# C-first raw-byte proof for a fireball's colour delivery, miss arm, caster at complete.
#
# skill_message brackets the caster's line with CCYEL/CCNRM and the victim's line
# with CCRED/CCNRM, but only at C_CMP (both PRF_COLOR bits); the room line carries
# no colour (src/fight.c:1049-1087). Fireball's own text in lib/misc/messages
# (set 26) has no colour codes, so every escape here comes from that delivery.
# keep-ansi compares the escapes raw (R1b).
#
# The caster sets its own level with `color`; the peers are created with the ANSI
# answer that gives them complete. That also proves the two gates are per-recipient:
# at sparse/normal the caster's own line is plain while the victim's is still red.
#
# depth-case: spell.fireball.color-complete-miss

#   save, then reallyquit outside a save room (LOSTEQ), then 1:
#     extraction finds RENT_CRASH and deletes the crash file

#     cryosave writes RENT_CRYO (:959-1005), which extraction keeps, so the
#     next entry logs it (:528).
#

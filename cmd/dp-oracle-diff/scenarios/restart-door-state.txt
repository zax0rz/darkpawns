# Door state does not survive a restart.
#
# C evidence: the rooms are re-read from the .wld files and reset_zone() then
# forces the reset table's door byte for every 'D' command it declares
# (src/db.c:2247-2281); the shutdown path writes nothing about doors
# (src/comm.c:288-293). A door a player opened is therefore closed again after a
# reboot. The Go port used to persist the open/closed/locked byte in
# data/world_state.json (RULEBOOK R4).
#
# The vehicle opens a door that starts closed, looks at the exit line, then
# restarts and looks again: the exit must read as closed once more.

# (src/interpreter.c:2195-2199). Quitting anywhere else would exercise
# DP-1310's still-open load-room path (docs/fidelity/depth/save.tsv).

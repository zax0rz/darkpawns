# depth-case: flee.then-walk-position
# A mortal fights the wharf rat, flees successfully, then walks and looks.
# The post-combat position reset (stop_fighting → POS_STANDING → update_pos,
# fight.c:230-252) is what lets the move through; without it the port
# answered "No way! You're fighting for your life!" (DP-1321).
#
# Shape notes: the primary is the God (empty-players) so the warmup can
# teleport the mortal out of the peaceful infirmary to Kir-Oshi's 18201; all
# six exits of 18201 and 18202 lead to the other room, so every flee
# succeeds on the first direction draw for every seed. C decrements a
# player's wait once per real game-loop pass (~10/s), not per pumped pulse,
# so the murder's WAIT_STATE (PULSE_VIOLENCE + 2 = 2.2 s) is drained by the
# ten pump steps' quiescence windows before the flee is sent; the single
# pump after the flee lets C's next violence pass run the fleer's
# stop_fighting before the move. The bare-fisted mortal drops to its wimpy
# level (5) during the ten rounds and auto-flees from live combat — the rat
# cannot kill it first (1d4 damage against a wimpy threshold of 5).

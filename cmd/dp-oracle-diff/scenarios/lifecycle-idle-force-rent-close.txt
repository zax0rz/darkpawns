# Lifecycle: a still-connected player past IDLE_DISCONNECT (30) is force-rented
# and disconnected, and the deterministic-clock harness survives the close.
# depth-case: idle.force-rent-closes-transport
# depth-case: idle.force-rent-no-menu
# depth-case: idle.force-rent-post-close-relogin
# depth-case: idle.force-rent-pump-deferred
#
# C (src/limits.c:438-451): at the 31st MUD hour a mortal in the void is moved
# to room 3, close_socket runs while the character is still CON_PLAYING (the
# room sees "$n has lost $s link.", comm.c:2131-2133), ch->desc is NULLed,
# free_rent's Crash_rentsave keeps the objects, and extract_char drops the
# character. `compare-close` makes the actor's closed transport a compared
# <CLOSE> line, and the closing <RELOGIN> proves the post-disconnect state.
#
# This is also the harness regression for the ~dpclock seam. Two connections
# are enough: the actor's descriptor is the driver's `next` in the game loop's
# input iteration, so a pumped heartbeat that closes the actor used to free the
# descriptor the loop still held (src/comm.c:577-583) and aborted the oracle
# with "*** bit out of range 0 - FD_SETSIZE on fd_set ***". The seam now only
# QUEUES pulses and the game loop drains them at its heartbeat phase, after
# descriptor input/command/output/prompt/CON_CLOSE processing, which is where
# production C runs them (src/comm.c:679). Before the fix this scenario kills
# the oracle; after it, the run is byte-identical to the port.
#
# Raising the void room's sector to SECT_INSIDE keeps the terminal pulse free
# of weather text. The terminal weather byte is an OPEN C/Go divergence (the
# port flushes queued output to a session it is about to close; C's
# close_socket discards it — finding F2 in
# docs/fidelity/depth/handoff/2026-09-27-idle-lifecycle-expansion.md). This
# vehicle proves the harness contract, not that byte; the raw blocks for the
# natural (weather-active) run are in the retained archive beside this PR.

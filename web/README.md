# web

HTTP-side support for the game server:

- `public/` is the browser client served at `/play`. `mud-client.js` renders
  the game into an xterm.js terminal over the `/ws` WebSocket; the admin
  console's terminal loads the same module.
- `auth.go` is the JWT bearer middleware for protected HTTP endpoints.
- `cors.go` and `security.go` set CORS and security headers.
- `errors.go` holds the shared JSON error helpers.

The OpenAPI specification is generated by the server from its registered
operations (Huma v2) and served at `/openapi.json`, with `/api/openapi.json`
as a compatibility alias.

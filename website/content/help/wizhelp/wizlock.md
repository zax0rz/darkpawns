Usage: wizlock [value]

[WIZLOCK](/help/wizhelp/wizlock/) allows you to restrict the game.  [WIZLOCK](/help/wizhelp/wizlock/) 1 prevents new characters
from being created.  [WIZLOCK](/help/wizhelp/wizlock/) n, 2 <= n <= 34, prevents new characters and
allows only characters level n and above to log on.  [WIZLOCK](/help/wizhelp/wizlock/) with no argument
displays the current [WIZLOCK](/help/wizhelp/wizlock/) level.

See also: [BAN](/help/wizhelp/ban-unban/)

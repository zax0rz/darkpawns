### Death is Free
- Corpses don't hold gear (`IsContainer` returns false for nil-prototype corpses)
- Corpse decay broken (no timer set, decay loop unreachable)
- `IsCorpse` field never set (auto-loot and mortician broken)
- `maxExpLoss` is 50000 instead of 500000 (10x too low)

### Server Crash Risks
- `doClanBank` nil pointer dereference (crashes on any bank interaction)
- `specMortician` nil deref if `IsCorpse` is ever fixed (reads `obj.Prototype.Keywords` on nil)
- Social system completely bypassed (different code path)

### Split-Brain Architecture
- `LVL_IMMORT`: 31 in `pkg/game/limits.go`, 50 in `pkg/session/wizard_cmds.go`
- Mortals at level 31-49 get immortal combat immunities but no wizard commands
- `backstabMult` duplicated in two packages

### Security Gaps
- WebSocket bypasses IP bans
- Muted players can spam socials
- Equipment class checks hardcoded false (clerics wield slashing, thieves use shields)

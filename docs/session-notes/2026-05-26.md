## Key Discoveries (This Session)

- `ExtractObject` in Go never recursed into containers — objects inside bags/corpses were orphaned in global map forever
- `ExtractPendingChars` only unequipped light sources — all other gear and inventory was lost on extraction
- Equipment `equip()` had zero alignment/class validation — players could equip restricted items without zap
- Spawner 'R' command only removed from local tracking, never called ExtractObject/ExtractMob — orphaned instances on every zone reset
- High-level mobs (level > 15) were significantly weaker than designed — C scales stats dynamically, Go didn't
- Rare items (ITEM_RARE) had zero variance — flag was completely ignored
- Mob gold was set exactly to prototype value — C randomizes +/- 20%
- Kill counter (`Kills`) was never incremented — `PKs` and `Deaths` aren't either

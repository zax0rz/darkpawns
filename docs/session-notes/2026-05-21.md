## What Happened

The Architect discovered I'd been running on DeepSeek for the P0-1 through P0-4 commits (the DP-Goat protocol layer). Asked me to review the work. I found three bugs:

### P0 Fixes (commit f3b2086)

**DP-245 (seq injection) — FRAGILE:** Raw JSON string injection assumed `"type"` was always the first key. Replaced with unmarshal → set seq → re-marshal.

**DP-246 (ANSI stripping) — BROKEN:** `stripANSI` scanned raw JSON bytes for `\x1b[`, but `json.Marshal` encodes ESC as `\u001b` — six ASCII characters, not one raw byte. The scanner could never match. Replaced with `stripANSIRecursive` that operates on decoded Go strings after unmarshaling.

**DP-247 (session handoff) — DATA RACE:** `takeOverPending` was a plain `bool` written by `Register` under `m.mu` and cleared by `readPump` with no lock. Changed to `atomic.Bool` for lock-free safe access.

**DP-248 (state vars) — CLEAN:** No changes needed.

### Daemon Foundation (commit f9bea89)

Built the persistent body layer — 1,034 lines across 4 new files:

- `reconnect.go` — exponential backoff + jitter reconnection
- `state.go` — persistent state at `~/.dp-goat/state/<name>.json` (atomic writes)
- `events.go` — append-only event buffer with seq tracking, compaction for LLM context
- `daemon.go` — Unix socket server at `~/.dp-goat/sock/<name>.sock`, routes CLI commands

### CLI Transport Patch (commit 9ecfb87)

Printing Press installed at `/Users/zach/go/bin/printing-press`. Fed it an OpenAPI spec describing 24 core MUD commands. It generated a full Go CLI with Cobra commands, MCP server, and OpenClaw skill.

The `--docs` approach failed (help pages aren't REST endpoints, LLM parsing failed). The `--spec` approach worked perfectly.

Transport patch: swapped the generated HTTP client for a Unix socket client (`DaemonClient`) that talks to our daemon. `--name <character>` flag routes commands through the socket. `--agent` mode for LLM consumption.

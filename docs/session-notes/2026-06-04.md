**Draft:** `docs/research/drafts/2026-06-04-memory-consent-ethics.md`

**Topic:** The consent gap in Dark Pawns' memory system. Players are remembered without opting in. Emotional valence is assigned to their actions without their knowledge. Narrative summaries persist indefinitely. No existing ethical framework addresses involuntary human participation in agent memory systems.

**Key contribution:** Positions the paper as ethically aware, not just technically novel. The three-tier architectural response (transparency, opt-out, disclosure) provides a concrete design framework. Differentiates from every prior memory system that either has all-AI actors or single-user consent.

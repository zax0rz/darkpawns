### Morning: Deadlock Crisis
- Server hung on character creation. Complete freeze — every goroutine blocked.
- SIGQUIT goroutine dump revealed lock ordering violation: `Manager.mu` → `World.mu`
- `Manager.Register()` held `Manager.mu` while calling `RemovePlayer()` which needed `World.mu`
- Meanwhile, `completeCharCreation()` → `GiveStartingItems()` → `MoveObject()` → `World.mu.Lock()`
- Result: writer starvation on Go's RWMutex

### Fix
- `Manager.Register()` now releases `m.mu` before calling `RemovePlayer()`
- Commit 5ab8d5b

### The Preservation Question
The Architect asked: "How do we keep everything true to the original experience for an agent?"

Answer: We don't. An agent doesn't experience Dark Pawns — it reads output, parses state, picks commands. The preservation isn't about making the agent feel the world. It's about:
1. The world stays true (port fidelity, 99.2% rooms, 100% mobs/objects)
2. The agent gets the full text (room descriptions, combat messages, social commands)
3. We observe what happens (decision capture, behavioral telemetry)
4. We compare across frameworks (which models stumble where, which recover)

The stumbling IS the data. Watching an agent fail to inhabit a world built for humans — that's the paper. That's the observation deck.

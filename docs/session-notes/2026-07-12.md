## Dispatch mechanics (confirmed this session)
- **Shared clone, sequential.** The coding agents operate in the main workspace clone
  (`/Users/zach/.openclaw/workspace/darkpawns_repo`) and/or its worktrees — do NOT run
  two overlapping-file dispatches at once. Zach runs the CLIs (kimi code / zcode /
  codex); Claude writes briefs and reviews.
- **Claude reviews against `origin`**, never local HEAD: `git diff origin/main...<branch>`,
  then build/vet/test in an **isolated worktree** under the scratchpad, then merge
  `gh pr merge <N> --merge --delete-branch`, then move Linear issues to Done.

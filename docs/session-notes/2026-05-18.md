### Server Protocol Analysis
- Server sends structured JSON via WebSocket:
  - `state` — player (HP, level, class, race, 6 stats) + room (vnum, name, desc, exits, doors, players, mobs, items)
  - `event` — typed: combat, enter, leave, say
  - `vars` — variable updates for agents
  - `token_refresh` — JWT rotation
  - `char_create` — structured character creation with stages/options/stat rolls
- Game features the client could leverage:
  - Doors (locked/closed state)
  - Combat events (typed, parseable)
  - Players in room (structured list)
  - Mobs/items (structured arrays)
  - Character creation (structured prompts)
  - Score sheet (all stats, equipment)
  - Who list (level + name + title)
  - Clans (full system — 20 clans, 20 ranks, bank, members)
  - Houses (ownership, guests, keys, rent)
  - Socials (full database)

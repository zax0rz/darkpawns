## Plans and history

[Briefs](briefs/README.md) are task specifications, not proof of open work or
completion. Check their status before executing them. Session notes, reports,
reviews, and research drafts preserve project history; their claims need checking
against current code and primary evidence. The [root archive](../archive/README.md)
contains retired handoffs and plans.

The older contributing and architecture documents remain available, but use
`AGENTS.md`, the fidelity rulebook, and the current depth-testing handoff when
older phase plans or port-completion claims disagree.

Official host access, secrets, deployment, and recovery procedures belong in the
private `zax0rz/darkpawns-ops` repository. Public instructions here describe how
someone can run their own instance.

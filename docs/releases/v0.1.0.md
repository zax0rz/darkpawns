Dark Pawns v0.1.0 is the first portable release of the Go server. It includes the
preserved Dark Pawns world, browser client and web administration console.

## Install and play locally

Download the archive for your operating system and architecture, extract it, then
run `darkpawns setup` (`darkpawns.exe setup` on Windows). The three-step wizard
chooses an instance folder and local port, reviews the settings, then launches
your world and opens the browser. The default address is `http://127.0.0.1:4350/`.
The first character created becomes the immortal. Create it before sharing access.

For one-command installation, use the shell or PowerShell instructions in the
[portable guide](https://github.com/zax0rz/darkpawns/blob/v0.1.0/docs/portable-release.md#bootstrap-installation).
Installers verify the publisher signature and archive digest before extracting.
Go, Node and a source checkout are not required to run a release.

## Included

- Linux, macOS and Windows archives for amd64 and arm64.
- A guided terminal installer with ASCII splash, keyboard navigation and plain
  prompts for screen readers or basic terminals.
- `start`, `stop`, `restart`, `status` and `doctor`, plus optional startup at sign-in
  through systemd user units, macOS LaunchAgents or Windows logon tasks.
- Manual `update`, signed official downloads, stopped-instance snapshots and
  recovery after a failed candidate launch. World edits and players live outside
  the replaceable release directory.
- Web world-building tools and a disconnected-player editor, including stats,
  inventory, equipment and password resets.
- Configurable Discord and Pushover notifications, with destination credentials
  managed through the admin console.

## Boundaries

This is an initial release for local installation and evaluation. Setup binds the
web client and admin console to loopback. Telnet and WHOD are disabled in generated
instances. Public hosting and adoption of an existing production installation
require deliberate configuration and migration; this installer does not convert
an existing checkout or custom system service.

Archives and release metadata are signed by the Dark Pawns publisher. Executables
are not Apple-notarized or Windows Authenticode-signed. Runtime journeys run in CI
on Linux, macOS and Windows; building all six archives does not prove runtime
behavior on every architecture or desktop security configuration.

Automatic updates and updater success/failure notifications are planned. Use
`darkpawns update --check` and `darkpawns update` for manual updates as subsequent
releases become available. This is the first versioned release, so a published
version-to-version update has not yet been exercised.

The game preserves the original C command surface and player-facing text under
fidelity rules R1–R5. Installation and administration are separate operator tools.
The original DikuMUD and CircleMUD license notices are included in every archive.

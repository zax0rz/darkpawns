Dark Pawns v0.1.1 adds explicit hosting configuration and a persistent service
manager for existing worlds. The game engine, world and player-facing text are
unchanged from v0.1.0 (R1 through R5).

- Configure telnet, TLS telnet and WHOD in `instance.json`. Ports are validated
  together; TLS and listener availability are checked before startup. Local setup
  keeps these listeners disabled by default.
- Explicitly configure TLS identity and Mudlet URLs. The launcher continues to
  isolate inherited settings from other installations.
- Releases now include the Mudlet package. An optional public directory receives
  the matching package atomically before the server advertises its version.
- `darkpawns supervise` gives an external service manager a stable foreground
  process across game updates. It respects deliberate stops, restarts a crashed
  game, and waits for interrupted-update recovery. Doctor reports monitor state.

Read the [hosting and adoption procedure](https://github.com/zax0rz/darkpawns/blob/v0.1.1/docs/portable-hosting.md)
before migrating an existing service. Preserve the original JWT, SQLite data,
complete world/state, boards, notification settings and original encryption key.
Sign-in startup and system supervision are separate ownership modes.

Existing v0.1.0 portable instances can use `darkpawns update --check`, then
`darkpawns update`. Configure hosting only after upgrading. Older launchers do not
understand the additional hosting fields; retain the original stable entry point
and use its dispatch to the active release. There is no automatic conversion of
an arbitrary checkout service, and no automatic update scheduling in this release.

Archives are available for Linux, macOS and Windows on amd64 and arm64. Native CI
covers each operating system; hosted listeners and system supervision have an
additional Linux integration journey. Cross-building an archive does not certify
every architecture or desktop security configuration. Apple notarization and
Windows Authenticode remain outside this release.

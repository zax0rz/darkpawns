Dark Pawns v0.1.2 fixes installation and admin entry issues and restores local
telnet access for new portable worlds.

- New instances listen on `127.0.0.1:7777` for telnet. Choose another port in
  setup, or enter `0` to disable it. Existing instances keep their configuration.
- Explicit bind addresses are available for telnet, TLS telnet and WHOD. Omitted
  hosted bind settings still mean all interfaces. The splash page lists sockets
  that actually opened, with their observed address and port.
- Direct `/login` loads reach the admin app. Room exit editors no longer crash
  when React defers a toggle update (#2117).
- Launcher help no longer prints the dispatch parser's usage. Setup questions
  have more spacing; operator commands use the short PATH command when it points
  to the same release, retaining an instance argument for custom worlds.
- Fresh release worlds show their build version instead of the 2008 pwipe notice
  and receive a neutral starter MOTD. The logo and CircleMUD/DikuMUD credits stay
  intact. Existing worlds retain their greeting unless `greeting_overlay` is
  explicitly enabled; their MOTD files are preserved.

Install on macOS or Linux:

```sh
curl -fsSL https://darkpawns.org/install.sh | bash
```

Read the [portable guide](https://github.com/zax0rz/darkpawns/blob/v0.1.2/docs/portable-release.md)
for Windows installation, bootstrap trust, management and recovery. Existing
installations can run `darkpawns update --check`, then `darkpawns update`.
Keep a v0.1.2-or-newer recovery launcher before adding new instance fields.

Apple notarization, Windows Authenticode and automatic update scheduling are not
included. Native CI covers Linux, macOS and Windows; this is not a claim about
every desktop security configuration. Network settings in the admin console
remain a design proposal.

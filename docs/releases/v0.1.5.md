Dark Pawns v0.1.5 fixes bugs that players reported on the live server, and stops a telnet negotiation flood. Every gameplay fix was checked against the original C source.

**Gameplay**

- Hunting mobs no longer walk through locked doors. Mobs open and close doors by the original command's rules, including doors whose names have more than one word (#2146, #2147, #2153).
- Holding a lit light lights the room you are standing in, and room light counts no longer drift as you move, drop or remove lights (#2151).
- Death clears spell affects, tattoo effects and werewolf and vampire forms, and mobs forget and stop hunting you, on every death path (#2158).
- Mana-regeneration equipment with a positive bonus counts only while you sleep, as in the original. Regeneration reads each item's own affects (#2161).
- `practice` shows the real proficiency for strike of revenge, serpent kick, dragon kick, tiger punch, escape of the mongoose, the kuji-kiri arts, pick lock, flesh alter, aid and search. These skills were always learned; only the list was wrong (#2160).
- Mobs that use player commands (say, tell, get, wear, flee, headbutt and others) run the real command (#2148).
- `track` is available, and `visible` makes a mortal reappear correctly (#2145).
- Scrounged food can no longer be duplicated (#2154).

**Server**

- The telnet listener no longer answers negotiations it has already agreed to. A client that acknowledges every offer used to start a flood of several megabytes per second (#2162).

**Testing**

None of these change gameplay: concurrent oracle censuses (#2155), a seed-player harness fixture that turns seven red draw-parity rows green (#2159), play-lab scenarios (#2150, #2157) and fixes for flaky tests (#2156).

Install on macOS or Linux:

```sh
curl -fsSL https://darkpawns.org/install.sh | bash
```

Read the [portable guide](https://github.com/zax0rz/darkpawns/blob/v0.1.5/docs/portable-release.md) for Windows installation, bootstrap trust, management and recovery. Existing installations can run `darkpawns update --check`, then `darkpawns update`.

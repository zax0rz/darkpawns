Dark Pawns v0.1.7 is the operator release. The admin console has been rebuilt, and you can now run, configure, update and watch your server from the browser. It installs through Homebrew, Scoop and Docker too. Nothing about the game itself changes, and every census against the original C source came back clean.

**Admin console**

- New look and layout: a sidebar, clearer pages and consistent icons (#2195, #2200, #2204).
- A dashboard showing who's online, new characters and player deaths, including what killed them. Click any tile for details (#2197, #2207, #2208).
- Server log and in-game log viewers, with export (#2197, #2207).
- Configuration in the browser: game settings, secrets and the network ports for telnet, TLS and the who-list. Changes that need a restart say so, and a bad change rolls back on its own (#2196, #2199, #2209).
- Updates: check for a new version and install it with one click. The updater refuses to install an older version by mistake (#2199).
- A player editor: rename or delete a character, set flags, and see and change everything they carry or wear, slot by slot (#2203, #2210).
- Notifications rebuilt, with a link to set up a healthchecks.io heartbeat (#2198, #2207).
- An editor for the message of the day, with a live preview of its colors (#2206).
- The front page now points new operators at the first step: create your immortal before anyone else logs in. It also links to the admin console (#2207).

**Command line**

- The `darkpawns` command is easier to read: tidier status, update and log output, with color where your terminal supports it (#2201).

**Installing**

- New ways to install: Homebrew (`brew install darkpawns/tap/darkpawns`), Scoop (`scoop bucket add darkpawns https://github.com/darkpawns/scoop-bucket`, then `scoop install darkpawns`) and a Docker image at `ghcr.io/darkpawns/darkpawns`. A winget package is waiting for Microsoft's review. Every channel installs the same signed release (#2205).

**Fixes**

- Fixed a crash in the launcher, and the timing problems that made it flaky on macOS (#2202).
- Settings that came from environment variables when the server was first installed no longer show up as manual overrides, and the release pipeline is hardened further (#2211).

Install on macOS or Linux:

```sh
curl -fsSL https://darkpawns.org/install.sh | bash
```

Read the [portable guide](https://github.com/zax0rz/darkpawns/blob/v0.1.7/docs/portable-release.md) for Windows installation, bootstrap trust, management and recovery. Existing installations can run `darkpawns update --check`, then `darkpawns update`. From this version on, you can also update from **Admin → Updates**.

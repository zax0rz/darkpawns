## CRITICAL

### Build break — nonexistent `Lockout()` getter on AccountLockoutTracker

**File:** `pkg/session/session_login.go:184`
**What:** Calls `s.manager.accountLockouts.Lockout().Minutes()` but `AccountLockoutTracker` has no `Lockout()` method. The `lockout` field is unexported (lowercase). This is a compilation error.
**Why it matters:** The session package won't compile. The telnet package (which imports session) also fails to build. Tests for both packages are blocked. The server cannot start.
**Suggested fix:** Replace the call with `IsLocked` which returns `(bool, time.Duration)` — the duration is the remaining lockout time:

```go
if newlyLocked := s.manager.accountLockouts.RecordFailure(login.PlayerName); newlyLocked {
    _, remaining := s.manager.accountLockouts.IsLocked(login.PlayerName)
    mins := int(remaining.Minutes())
    ...
}
```
**Effort:** S (one-line change in session_login.go, no API changes needed)

## Test Quality Issues

### Tests that are value-only, not behavior-verification

- **pkg/metrics/metrics_test.go** — Tests verify metric names appear in HTTP output but NEVER assert actual metric values. Logic bugs in wrapper functions (e.g., ConnectionOpened passing wrong count) go undetected.

### Skipped tests

- **pkg/game/combat_test.go:87,119** — Two tests skip when weapon vnum 3002 isn't available. These are data-dependent skips that mean CI without the world files silently runs fewer tests.
- **pkg/events/lua_integration_test.go:43** — Skips when `test_scripts` directory not found. Again, data-dependent.
- **cmd/dp-goat/internal/cliutil/cliutil_test.go:571** — Skips slow timeout test in -short mode (acceptable).

### Missing table-driven tests

33 of 73 test files use table-driven patterns. The remaining 40 write one-test-per-function which inflates file count without covering edge cases well. Specific packages where table-driven would help:
- **skill_commands.go** (40+ functions) — zero tests at all
- **game/combat_*.go** — damage formula variants, weapon types, armor classes
- **game/spec_*.go** (8 files) — special proc dispatch

### Nothing tests concurrent safety

Zero tests verify concurrent access patterns. The race detector and `-race` build tags exist (`cmd/test-race`) but are not wired into `go test` or CI. Concurrent door/shop access, affect manager ticks, and zone resets are all vulnerable to races without test coverage.

## Priority Recommendations

1. **P0 — pkg/command/skill_commands.go** — Add tests for the 40+ skill commands. Each command is a self-contained handler that takes (session, args) and returns error. Easy to unit-test with mock sessions. Highest value per line of test code.

2. **P0 — pkg/game/combat_basic.go + combat_control.go** — doHit(), doKill(), doFlee() are the core combat loop. No tests means every combat path change is a blind merge.

3. **P1 — pkg/game/act.go + act_comm.go** — Act(), oneArgument(), halfChop(), isNumber() are the message formatting and text parsing foundation. If these break, the entire game output breaks.

4. **P1 — pkg/game/mobact.go** — MobileActivity() is the mob AI entry point. Untested means mobs can silently break (stop moving, stop attacking, stop responding).

5. **P2 — pkg/telnet/listener.go + pkg/session/session_player.go** — The connection lifecycle (telnet accept → session create → player bind → close) has zero tests. Connection handling regressions are invisible until prod.

6. **P2 — pkg/game/spec_*.go** — All 8 special proc files at 0%. These are the unique zone/mob behaviors that make the world feel alive. No tests means any refactor is blind.

7. **P3 — pkg/optimization** — Zero tests on performance infrastructure. If the connection pool or room cache breaks, the server degrades silently.

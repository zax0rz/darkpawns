## How things work (patterns you'll need)

**Command dispatch:** single `cmdRegistry` (`pkg/command/registry.go`), entry
`ExecuteCommand` (`pkg/session/commands.go`). Spec procs (mob/room/obj) intercept
*before* registry lookup. **No abbreviation matching** — register explicit aliases.

**Wiring a skill that already has a handler** (`pkg/command/*Cmd<Name>`):
```go
// in pkg/session/commands.go init()
cmdRegistry.Register("disarm", wrapSkill(command.CmdDisarm), "help text", 0, combat.PosFighting)
```
Positions/levels come from `src/interpreter.c`. `wrapSkill` adapts
`func(command.SessionInterface, []string) error`.

**A combat skill's logic** lives in `pkg/game` as `DoX(ch, target) SkillResult`;
the `pkg/command` handler just gates (`game.CanUseSkill(ch, game.SkillX)`), parses
args, calls `DoX`, returns `sendSkillResult`. See `CmdBash` + `game.DoBash`.

**Timed buffs/debuffs:** build `engine.NewAffect(spellID, location, duration,
magnitude, source)` and call `ch.AddAffect(aff)`. Stat getters now sum these via
`Player.sumAffectModsLocked(location)` for `ApplyHitroll/ApplyDamroll/ApplyAC`.
Expiry (`affect_update.go` / `RemoveAffectBySpell`) auto-reverts. **AC sign:**
lower is better; store the magnitude with the C sign (armor −15 improves, berserk
+25 worsens) — getter folds it by addition.

sanctuary routed through a separate `AffectManager.ApplyAffect` path where
their stat debuffs never applied. Re-verified directly against the code: that
claim was wrong. `spells.Cast`'s `am *engine.AffectManager` param was already

only function that would have used `AffectManager` for spell effects — had
zero callers anywhere. Every spell, including those five, already went
through the one live path (`CallMagic → MagAffects → applyAffect → AddAffect
→ ActiveAffects`). Cleanup PR deleted `engine.AffectManager`,
`AffectTickSystem`, `TickManager`, `spells.ApplySpellAffects`, the dead
`common.Affectable` interface, and dropped the unused `am` param from
`spells.Cast` (and all call sites).

Still flagged, not fixed: a *third* dead system —

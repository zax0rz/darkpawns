## Ground truth (verified by Claude at `origin/main` b7fdd6ef5)

**C:**
- `sprintbitarray` (`src/utils.c:825-843`) passes each `int` word as `(bitvector_t)bitvector[i]` (`:835`). `bitvector_t` is `unsigned long int` (`src/structs.h:697`), 64 bits on the reference build. So an `int` word with bit 31 set **sign-extends** to bits 31–63 all set.
- `sprintnbit` (`src/utils.c:799-821`) walks every set bit, shifting until the value is 0 (64 iterations for such a word). For each set bit it prints `names[nr]` followed by a space, or `"UNDEFINED "` once `names[nr]` is the `"\n"` terminator. `nr` stops advancing at the terminator.
- `names + i*32` is a pointer into one flat table. So bits 32+ of word 0 read the *next word's* names, until the terminator.
- `AFF_FLAMING` is bit 31 (`src/structs.h:341`).

# Docs pass 2: grouped commands and help archive

**Purpose:** Replace the public per-command link pages and Help museum routes with a generated, grouped Reference section. Players can look up the complete original help text by topic and link directly to a stable topic anchor.

**Source:** Classification metadata (titles, aliases, and museum slugs) comes from `website-astro/src/content/help/{commands,info,socials,spells,wizhelp}/`. Every displayed body is read directly from the corresponding `lib/text/help/{commands,info,socials,spells,wizhelp}.hlp` record. The taxonomy parses records using the same keyword-line / first-byte-`#` boundary used by Go `LoadHelpFiles` and C `load_help`; it preserves source line endings, blank lines, indentation, punctuation, and entities as literal source text. The Markdown archive body is not used for output because it can contain rendered links or escaped characters that were never in-game.

**Classification:** Original help text is marked **Verbatim** and is placed unchanged in fenced code blocks. New framing is short Reference prose. Command topics use the task taxonomy (Combat, Movement, Communication, Objects, Information, Groups, Character, Settings, System); other help topics use Spells, Socials, Information, or Immortal commands. Topics keep their source filename slug as a stable anchor.

**Completeness proofs:** `node website-astro/scripts/check-command-docs.mjs` runs after docs generation during the site build. It independently parses all 429 records from the five original `.hlp` files, verifies each is mapped to exactly one museum topic, and extracts each generated code block to compare it byte-for-byte with that raw record. It checks every canonical HTML/Markdown museum URL, legacy alias, category index, and old per-command docs URL redirects to its new group anchor. The same taxonomy helper supplies routes to Astro and the content inventory; it contains no per-topic redirect table. ASSIST is a negative example: the original line `Usage: ASSIST <person in need>` remains literal; generated output does not inherit archive links such as `[ASSIST](/help/...)` or an escaped `&lt;`.

**R1:** This is a website reference migration. Output bodies now come from the player-facing source records in `lib/text/help/*.hlp`, preserving their original bytes instead of the transformed Markdown archive; it does not change game behavior.

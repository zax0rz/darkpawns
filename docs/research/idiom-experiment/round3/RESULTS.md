# Round three: session and spells mutation sample

## Method and preregistered predictions

This continues the PF-102 one-byte mutation method on the frozen `pkg/session` and `pkg/spells` populations. The source base for both populations and every probe was Part 1 commit `aa867bf4dfa25c0fcafe337c11071d56ed7aee40`. Each package contributed 40 randomly drawn functions using the seeds and literal-selection procedure recorded in [PREDICTIONS.md](PREDICTIONS.md); the first ASCII letter of each chosen output literal was changed to `Q` (or `Z` when it was already `Q`). Predicted scenarios were frozen in [run/probes.tsv](run/probes.tsv) before each census.

Round two’s population collector was corrected for one-argument selector calls. Regenerating its historical population at `5e9556a8789c4125bed8913d34d16e6f2ed68fac` added **2 function rows** (`Dream` and `DreamTravelFn`) and **29 eligible literals**; the frozen round-two sample and denominator remain unchanged. The round-three population files and their hashes are recorded in [PREDICTIONS.md](PREDICTIONS.md).

Every mutation received one full census. An uncaught probe whose full census was red only on unrelated scenarios received exactly one full recheck. If that recheck remained red only for unrelated failures, its result is recorded as `infra` and excluded from the conclusive catch-rate denominator. Exact per-probe first and recheck directories are listed below and in the `census_dir` column of [run/probes.tsv](run/probes.tsv).

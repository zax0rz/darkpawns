# DP-1535 combat skills: utility batch 1

## Scope

This stop-tier batch adds switched-mobile actor routes for `aid`, `alter`/`flesh`,
`bearhug`, `behead`, `berserk`, and `bite` (seven registry keys across six C
handlers). Player bodies keep the existing skill handlers. The mobile path uses
`CharacterCommandContext`; it reads the mobile's room, skills, equipment,
affects, health, combat state, and waits while descriptor output remains on the
session.

The route registrations are in `pkg/session/commands.go`; the body handlers are
in `pkg/game/skill_actor_selected.go`. `pkg/game/mob.go` adds point adjustments
used by flesh alteration, and `pkg/game/skill_special.go` preserves behead's C
actor-message ordering before object mutation. No files under `src/` or
`darkpawns-c-oracle/` changed.

  body skill, wielded item, flesh-alter affect, hitroll, and damroll in

  gates in `src/new_cmds.c:471-547`.
- `behead` resolves a room object and selects its message from the body's
  wielded weapon in `src/new_cmds.c:216-300`.
- `berserk` reads the body skill and installs body affects and waits in
  `src/new_cmds.c:2134-2185`.

  player damage in `src/new_cmds.c:1199-1268`.

NPC skills are the shared `dummy_mob` values (`src/db.c:104,1281;
src/utils.h:343`). `do_restore` sets those skills to 100 for an immortal-level
mobile restored by a greater god (`src/act.wizard.c:1599-1601`). The mobile
routes follow that shared state rather than borrowing the descriptor owner's
skills. The C calls to `WAIT_STATE` in handlers reached by a mobile are mirrored
in the actor path; the zero-skill early returns remain before those waits.

## Source boundary

C `damage()` enrolls the attacker only above POS_STUNNED and when not already
fighting (`src/fight.c:1400-1408`). The attacker position gate ends at `:1442`; independent victim enrollment
requires victim position above POS_STUNNED and no existing
FIGHTING (`:1443-1445`). `set_fighting` changes position to POS_FIGHTING
(`:222-223`). After wounded messages, `!AWAKE` stops the victim (`:1630-1632`);
AWAKE means position strictly above POS_SLEEPING (`src/utils.h:450`).

The command tail needs to register the surviving attacker without resurrecting
that stopped victim. `StartCombatAfterDamage` uses the completed damage state;
ordinary opener entry retains its deferred victim posture check. The secondary
smackheads tail excludes unconscious attackers. `EnterDamageFighting` supplies
the same initial field/position gates for the plain damage seams.
`TestDamageVictimEnrollmentIndependentOfAttackerPosition` drives a stunned
attacker against a fresh victim through both damage seams and the real engine;
only the victim joins the combat list. The full seam keeps the victim and
MOB_HUNTER gates outside the attacker-position gate, as C does.

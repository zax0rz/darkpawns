## Other readers and lock acquisitions

Force's room/level snapshots release manager/body locks before Act. ToVict
checks recipient state, renders PERS and sends through the existing player
world sink, heartbeat transaction, snoop/switch and transport paths. No new
lifecycle lock, manager lock held across callbacks, registry or output queue.
Forced interpretation and mudlog ordering are unchanged. Shutdown snapshots
sessions under manager RLock and releases it before Act and ExecSave.

Whod Mode is existing game-loop state, initialized in NewWorld. A repository
sweep of ExecWhod/DoWhod/WhodDisplay/BuildWhoList finds the live session command,
World bridge, constructor and tests; BuildWhoList has no transport caller.
No admin, save, browser or persistence consumer is silently treated as parity.
The historical claim that WebSocket who replaces the C daemon is removed;
that replacement has no approved divergence or live WHOD call path.
Mode reads/writes acquire no new locks. The synchronous session output callback
finishes its existing heartbeat/send locking before MudLog. The producer is
called with no world/body/manager/lifecycle lock held. The shared provider
snapshots sessions then releases manager RLock before recipient callbacks;
player/world sink lookups release their locks before transport delivery.
No global broadcast or second MudLog implementation.

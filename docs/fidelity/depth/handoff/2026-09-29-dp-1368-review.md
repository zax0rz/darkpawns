Under DP_CLOCK, C waits expired on real loop passes while Go counted pumped heartbeats, so slower harness pacing masked fidelity errors. This change counts C waits in pumped pulses and restores Go’s additive wait counts, victim stand gate and integer position damage to the executed C (R1/R3b/R3c/R4/R5c/R5h; brief and Addenda1–5).

before each pumped heartbeat, dispatching at most one queued command per
ready descriptor. The normal-mode decrement, wait=1 reset, alias/menu/editor
handling, and heartbeat order remain preserved by the shared dispatch helper
and source-comparison test. The C self-test drives an actual editor descriptor:
`dp-seam-selftest: wait-counts-pulses idle=2 pumped=0 released=1`.

## Victim posture

C `damage()` calls `set_fighting(victim)` only for `!FIGHTING(victim)` and
`GET_POS(victim)>POS_STUNNED` (src/fight.c:1443-1445), after the to-hit and
prone-damage calculations. Go now preserves that gate on hit and miss. A
pending posture flag retains the initial transition because Go eagerly sets
the fighting target at entry while delaying the posture transition until
that damage point. It is consumed once, so a second swing cannot stand a
fighter who subsequently sits.

`TestVictimStandRequiresNewCombatOnHitAndMiss` covers fresh victims, existing
fighters targeting the attacker or a third party, and second swings, for both
hit and miss. Removing the fighting gate fails the existing-fighter halves;
removing the pending initial transition fails the fresh-victim halves.
Unedited `bash-failure-depth` matches C, including
`You drag yourself to your feet.` Unedited `combat-entry-peaceful-wait` is green.

Other engine posture paths audited: startCombat's attacker transition follows
command entry; PerformUnenrolledInitialAttack gates on an empty attacker
fighting target; processCombatPair's NPC and PC stand-up paths implement
perform_violence's separate round rules (fight.c:1975-1998, PC CHECK_WAIT gate).
These are not victim-on-damage transitions and were unchanged. Game damage
helpers set fighting targets but contain no unconditional posture setter.

- THREE stacked divergences fixed (R5c — the whole flag-line/innate-affect
  class):
  1. Parser read flag word 2 as the AFFECTED word. db.c parse_mobile reads
     EIGHT flag words — act 1-4 into MOB_FLAGS[0..3], AFFECTED 5-8 into
     AFF_FLAGS[0..3] — then alignment (word 9), then the type letter. Also
     fixed in the same block: alignment was read from word 3 and race from
     word 4; C reads race ONLY from the "Race:" extra line (default
     RACE_OTHER=7). 950 world mobs carry nonzero innate affect words (0.mob
     alone: recharger has innate sanctuary, skull innate waterbreathe bits).
  2. NewMob never seeded proto AffectFlags onto the instance (same class as
     #661's act-flags fix): mob.Affects now starts from
     affectFlagBits(proto.AffectFlags) in C struct positions.
  3. The mag_affects gate tested ENGINE flag positions against the C-position
     mask (sanctuary engine bit 4 vs C bit 7). affectGateFlags now returns raw
     C positions and npcInnatelyAffected tests BOTH slots unconditionally —
     C's unset af[1].bitvector == 0 tests the AFF_BLIND bit, so an innately
     blind mob refuses single-affect spells (quirk unit-pinned by
     TestMagAffectsMobInnateGateUnsetSlot).
- Vehicle unlock: ClassSkillMinLevel returned 999 for class-unassigned
  spells; C's spello() defaults every class to LVL_IMMORT (31) — that is why
  the warrior God could cast sanctuary on C but Go answered "You do not know
  that spell!". Reserved ('!'-prefixed) slots stay LVL_IMPL+1.
- Harness timing note (important for multi-cast probes): C clears wait_state
  on MAIN-LOOP passes (wall clock) and the ~dpclock heartbeat pump does NOT
  drain queued input or decrement wait on the C side, while Go's pulse pump
  does. A second cast after WAIT_STATE(PULSE_VIOLENCE) therefore silently
  queues on C but executes on Go — asymmetric harness timing, not game
  bytes. Multi-cast scenarios need wall-clock gaps or single-cast probes.
- Pre-existing REDs on main (NOT this round's regressions, verified by

  sessions remaining." line in the practice list) and backstab-aware-trio.
  Both deserve their own fix rounds.

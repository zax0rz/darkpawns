# DP-1322 — the zone-144 skull rider was a persisted wander position

Production saw a zone-144 skull rider west of the Temple Altar (Kir Drax'in,
zone 80) on 2026-09-23, three days before `d4b3298c7` removed the world-state
reload. The reload is the explanation.

## The mob

- VNum 14431, loaded by zone 144's reset eight times at room 14400
  (`M 0 14431 8 14400`), all inside the Grey Keep.
- Its action bitmask is 1308728. C's MOB_STAY_ZONE is bit 6 and MOB_SENTINEL
  bit 1 (`src/structs.h:248,253`); neither bit is set (the bits are
  20,17,16,15,14,13,12,11,5,4,3). The rider is not a sentinel and is not
  zone-bound, so C's own wander may walk it through a zone boundary
  (`src/mobact.c:117-129`).
- Go's wander has the same gate: `hasMobFlag(mob, "stay_zone") && targetRoom.Zone
  != room.Zone` (`pkg/game/ai.go:120-121`). With no flag the gate is irrelevant
  in both engines.

## The reload

Before `d4b3298c7`, `saveMobPosition` captured every active mobile's room and
HP, and `DeserializeWorld` replayed them **after** the boot zone resets:

```go
for _, saved := range sd.Mobs {
  ...
  mob.RoomVNum = saved.RoomVNum
  ...
}
```

The assignment had no room or zone validation. A rider that had wandered out
of zone 144 (legal in C), been charmed and walked, or been summoned to Kir
Drax'in kept that room across every restart, so production saw a zone-144 mob
parked in zone 80 — exactly the 2026-09-23 report.

## Current code

- `d4b3298c7` removed the replay; `IgnoreLegacyWorldState` only reports a
  leftover snapshot and never restores mobs (`pkg/game/world_state.go`). Boot
  rebuilds every mobile from the reset tables at its home room.
- Zone 144's reset room is 14400, inside the zone; nothing places the rider in
  Kir Drax'in.
- Gates/portals, charm/follow and summon remain C behavior; none of them lets a
  **STAY_ZONE** mob wander out, and the Go gate matches C.

## R5b — the class

The reload affected **every** mobile's saved room and HP, not just the rider:
any mob that had moved from its spawn room persisted there across restarts.
Removing the replay covers the class.

## Conclusion

No live path lets a STAY_ZONE mob leave its zone; the skull rider does not have
the flag and C would let it wander too. The production sighting is explained by
the removed reload; recommend closing DP-1322.

# F7: Cloudflare + TCP Reachability

## Findings

### [1] Cloudflare Spectrum custom TCP/UDP proxying requires Enterprise plan (custom pricing, not publicly listed)
- quote: "Custom TCP/UDP applications require an Enterprise plan with Spectrum as a paid add-on."
- url: https://developers.cloudflare.com/spectrum/
- source_type: primary
- published: 2026-04-23
- confidence: high

### [2] On Pro/Business plans, Spectrum only supports Minecraft (1 app), SSH (1 app), and RDP (Business+ only, 1 app) — no generic TCP/UDP passthrough
- quote: "TCP: Free=No, Pro=No, Business=No, Enterprise=Paid add-on. UDP: Free=No, Pro=No, Business=No, Enterprise=Paid add-on. Minecraft (one app allowed): Free=No, Pro=Yes, Business=Yes, Enterprise=Yes. SSH (one app allowed): Free=No, Pro=Yes, Business=Yes, Enterprise=Yes."
- url: https://developers.cloudflare.com/spectrum/protocols-per-plan/
- source_type: primary
- published: 2026-04-16
- confidence: high

### [3] Spectrum operates as a Layer 4 reverse proxy — it terminates TCP connections on both sides and passes payloads as-is, making it suitable for raw telnet if you can afford Enterprise
- quote: "Spectrum is a global TCP and UDP proxy running on Cloudflare's edge nodes. It does not terminate the connection in the application-layer sense. However, at Layer 4, Spectrum does terminate the TCP and UDP sockets in both directions. The L4 payloads of TCP segments and UDP datagrams are passed back and forth as-is, without modifications."
- url: https://developers.cloudflare.com/spectrum/reference/configuration-options/
- source_type: primary
- published: 2026-06-23
- confidence: high

### [4] Cloudflare Tunnel for private networks (cloudflared) can proxy TCP traffic but requires end users to install the Cloudflare One Client (WARP) — it is NOT a public-facing TCP proxy
- quote: "On the client side, end users connect to Cloudflare's global network using the Cloudflare One Client. The Cloudflare One Client can be rolled out to your entire organization in just a few minutes using your in-house MDM tooling. When users connect to an IP address or hostname made available through Cloudflare Tunnel, WARP sends their connection through Cloudflare's network and down the corresponding tunnel to the internal service."
- url: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/
- source_type: primary
- published: 2026-04-17
- confidence: high

### [5] Spectrum supports virtual network origins — combining Spectrum (Enterprise) with Cloudflare Tunnel to reach private origins over TCP without exposing the origin IP
- quote: "Spectrum routes traffic through the connector (Cloudflare Tunnel or Cloudflare WAN connection) associated with that virtual network. This provides an alternative to the previous pattern of putting a load balancer in front of a private origin."
- url: https://developers.cloudflare.com/spectrum/get-started/
- source_type: primary
- published: 2026-06-23
- confidence: high

### [6] DNS-only ("grey cloud") records in Cloudflare expose the origin IP directly — Cloudflare does NOT proxy non-HTTP traffic through proxied A/AAAA records
- quote: "When a record is DNS-only, Cloudflare responds with your server's actual IP address and does not route HTTP/HTTPS traffic through its network."
- url: https://developers.cloudflare.com/dns/proxy-status/
- source_type: primary
- published: 2026-04-21
- confidence: high

### [7] Caddy is an HTTP/HTTPS reverse proxy and has no capability to proxy raw TCP connections — it cannot serve as a telnet relay
- quote: (No explicit quote — Caddy's documentation and architecture only describe HTTP/HTTPS/gRPC/WebSocket reverse proxying. TCP proxying is not a supported feature.)
- url: https://caddyserver.com/docs/caddyfile/directives/reverse_proxy
- source_type: primary
- published: unknown
- confidence: high

### [8] Spectrum Enterprise pricing is custom and not publicly listed — typical Enterprise contracts start around $1,000-5,000+/month depending on traffic volume and features negotiated with account team
- quote: "Custom TCP/UDP applications require an Enterprise plan with Spectrum as a paid add-on... contact your account team to enable."
- url: https://developers.cloudflare.com/spectrum/reference/settings-by-plan/
- source_type: primary
- published: 2026-04-16
- confidence: medium

### [9] The most common MUD hosting pattern in 2025-2026 is direct IP exposure on a VPS/dedicated server with the MUD listening on port 7777 (or similar), relying on the host's firewall rather than a CDN — Cloudflare is not widely used for raw telnet MUDs due to the Spectrum Enterprise cost barrier
- quote: (Synthesized from absence of community/forum evidence of MUD operators using Cloudflare Spectrum for telnet, combined with the protocol restriction table showing no generic TCP support below Enterprise tier.)
- url: https://developers.cloudflare.com/spectrum/protocols-per-plan/
- source_type: primary
- published: 2026-04-16
- confidence: medium

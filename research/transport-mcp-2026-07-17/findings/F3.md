# F3: MUD Web Client Landscape 2025-2026

## Findings

### [1] maldorne/mud-web-client v4 (2026) is a full Vue 3 + TypeScript + xterm.js rewrite that builds to static files via Vite
- quote: "In 2026, the project was rewritten from scratch using Vue 3, TypeScript, and xterm.js. This is no longer a fork — it is a completely new implementation designed for modern browsers, with a clean component architecture, proper telnet protocol parsing, and Docker support."
- url: https://github.com/maldorne/mud-web-client
- source_type: primary
- published: 2026
- confidence: high

### [2] maldorne/mud-web-client supports GMCP, MSDP, and MXP protocols with a byte-level IAC parser
- quote: "GMCP protocol support (bidirectional), MSDP protocol support, MXP protocol support"
- url: https://github.com/maldorne/mud-web-client
- source_type: primary
- published: 2026
- confidence: high

### [3] maldorne client's telnet parser implements GMCP/MSDP at byte level in a composable (useTelnetParser.ts), parsing IAC subnegotiations before UTF-8 decoding
- quote: "This two-phase approach (bytes → strip IAC → decode UTF-8) prevents IAC bytes (0xFF etc.) from being mangled by TextDecoder."
- url: https://raw.githubusercontent.com/maldorne/mud-web-client/master/src/composables/useTelnetParser.ts
- source_type: primary
- published: 2026
- confidence: high

### [4] maldorne client uses @xterm/xterm v6.0.0+ with fit and web-links addons; no status-bar or GMCP-display addon is included
- quote: dependencies include `"@xterm/xterm": "^6.0.0"`, `"@xterm/addon-fit": "^0.11.0"`, `"@xterm/addon-web-links": "^0.12.0"`, `"golden-layout": "^2.6.0"`
- url: https://raw.githubusercontent.com/maldorne/mud-web-client/master/package.json
- source_type: primary
- published: 2026
- confidence: high

### [5] All maldorne client configuration is via URL query parameters with no config files or environment variables needed
- quote: "Parameter: proxy, host, port, mud, name, ttype, debug, separator — All configuration is done through URL query parameters. No config files or environment variables are needed."
- url: https://github.com/maldorne/mud-web-client
- source_type: primary
- published: 2026
- confidence: high

### [6] maldorne/mud-web-proxy v4 (2026) is a companion WebSocket-to-Telnet proxy with MCCP v2, MXP, MSDP, GMCP, auto-reconnect, rate limiting, and Prometheus metrics
- quote: "MCCP v2 compression support (zlib), MXP (MUD eXtension Protocol) support, MSDP (MUD Server Data Protocol) support, GMCP / ATCP protocol support (bidirectional)"
- url: https://github.com/maldorne/mud-web-proxy
- source_type: primary
- published: 2026
- confidence: high

### [7] maldorne client builds to a static /dist directory served via nginx in a multi-stage Docker build (node:20-alpine build + nginx:alpine runtime)
- quote: "Multi-stage Docker build (node:20-alpine + nginx:alpine)" and `"build": "vue-tsc --noEmit && vite build"` producing `/dist`
- url: https://github.com/maldorne/mud-web-client
- source_type: primary
- published: 2026
- confidence: high

### [8] maldorne client supports responsive layout from 800x600 iframe to fullscreen
- quote: "Responsive layout (works in 800x600 iframe and fullscreen)"
- url: https://github.com/maldorne/mud-web-client
- source_type: primary
- published: 2026
- confidence: high

### [9] Mudlet (4.22, July 2026) has no web-based client; it is a desktop-only Qt/C++ application with Lua scripting
- quote: "Mudlet runs on Windows, macOS, and Linux-based OS (even Chromebooks and Raspberry Pi)." No mention of browser/web version anywhere on mudlet.org.
- url: https://www.mudlet.org/
- source_type: primary
- published: 2026-07-06
- confidence: high

### [10] xterm.js v6.0.0 (Dec 2025) is the current stable release; it is the terminal engine used by VS Code, with 20.9k GitHub stars and GPU-accelerated rendering via WebGL addon
- quote: "6.0.0 Latest — Dec 22, 2025" and "Xterm.js is a frontend component that enables applications to bring fully-featured terminals to their users in the browser. It's used by popular projects such as VS Code"
- url: https://github.com/xtermjs/xterm.js
- source_type: primary
- published: 2025-12-22
- confidence: high

### [11] MUDPortal-Web-App (plamzi) is the jQuery-based predecessor to maldorne; it also supports GMCP/MSDP/MXP but uses no modern build system and is licensed GPL-2.0
- quote: "GMCP / ATCP protocol support (JSON) with sample uses in multiple existing plugins, MXP protocol support built into the client, MSDP protocol support"
- url: https://github.com/plamzi/MUDPortal-Web-App
- source_type: primary
- published: unknown (last commits unclear)
- confidence: high

### [12] No other actively maintained xterm.js-based MUD web clients with GMCP support were found beyond maldorne and MUDPortal
- quote: GitHub search for "mud web client xterm GMCP" returned 0 repository results.
- url: https://github.com/search?q=mud+web+client+xterm+GMCP&type=repositories
- source_type: primary
- published: 2026-07-17
- confidence: high

## Dead ends
- WebSearch tool was unavailable during this session; all research was via direct URL fetches.
- BeipMU web client (nicknassar/beipmu or beipmu-web) returned 404 on GitHub; appears not to exist as a public repo.
- Mudlet features page (mudlet.org/features/) returned 404; used main site instead.
- GitHub repository search for "mud web client xterm GMCP" returned zero results, confirming maldorne is essentially the only modern option.

## Suggested follow-ups
- Inspect maldorne client's `MudTerminal.vue` and `useSocket.ts` for how GMCP events are surfaced to the UI (status bar integration gap).
- Evaluate whether the maldorne client's `golden-layout` dependency adds useful panel/pane support or is dead weight for a single-MUD deployment.
- Investigate building a minimal in-house xterm.js client (~200 lines) vs forking maldorne, given the telnet parser is the hardest part and is already cleanly factored into `useTelnetParser.ts`.

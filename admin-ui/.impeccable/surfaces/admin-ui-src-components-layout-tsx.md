# Admin console foundation

Mode: Operate. Existing console, extended within the Haunted Paperback system.
Audience: immortal operators and world builders. Preserve the wordmark, static
sidebar and working-area structure, page content, permissions and save boundaries.
The dashboard is the quality benchmark: make health and next actions legible at
a glance. Data histories and page charts belong to plan B after this foundation.

## Direction contract

THESIS: A consistent operator console whose controls remain familiar under dense
world editing and failure states. The existing layout is fixed by Zach's brief.

OWN-WORLD: Inherit the site's two creams, charcoal rules, sparse oxblood, bundled
serifs and machine-only monospace. Square controls, no shadows or blur. Lucide
line icons distinguish destinations; the pawn keeps its canonical geometry.

STORY: Locate the task, inspect the record, edit through labelled controls, then
see whether the server accepted the change. Errors and unsaved state stay visible.

FIRST VIEWPORT: Wordmark and grouped static navigation at left. Compact toolbar
above a working area with a fixed-size title, supporting copy, existing metrics
or filters, then the current task. Primary save actions retain their existing place.

FORM: Extension of an established surface, chosen by the supplied plan. The
brief pins both the world and composition; no concept roll or seed applies.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

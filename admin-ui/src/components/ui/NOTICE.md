# shadcn/ui source

These components were copied from the official shadcn/ui Radix registry using
shadcn 4.23.0, then adapted for Dark Pawns' Haunted Paperback tokens and single
light theme. The original license is retained in `LICENSE.shadcn`.

Source: https://github.com/shadcn-ui/ui
Registry: https://ui.shadcn.com/r/styles/new-york

Local adaptations include square corners, paper surfaces, ink rules, no shadows,
Lucide icons, and a light-only chart container. NativeSelect retains standard
form events for the existing schema-driven editors. The component preview is a
development-only entry and is not included by the production Vite build.

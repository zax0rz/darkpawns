Usage: put &lt;item&gt; &lt;container&gt;
       put all.&lt;item&gt; &lt;container&gt;
       put all &lt;container&gt;

For putting items into containers.

Examples:

  > put bread bag
  > put all.bread bag
  > put all chest

See also: GET

Short meanings for terms used in the game and these docs.

| Term | Meaning |
| --- | --- |
| AC | Armor class, a character's defensive rating. |
| AFK | Away from keyboard. The `afk` command tells people who send you a tell that you may not see it. |
| GRGOD | Staff level 38. |
| guild | A class's guarded place to learn and practice its skills. |
| HIGOD | Staff level 36. |
| HP | Hit points, a character's health. |
| immortal | Staff level 31 or higher. |
| implementor | Staff level 40. |
| linkdead | A character whose client disconnected while the character remains in the game. |
| mob | A mobile non-player character controlled by the game. |
| MOTD | Message of the day, the welcome text shown when a character enters. |
| MP | Mana points, used to cast spells. |
| MUD | Multi-user dungeon, a text-based multiplayer game. |
| MV | Movement points, spent while travelling and on some actions. |
| newbie | A player who is new to MUDs or new to a particular MUD. |
| PK | Player killing, combat between player characters. |
| practice | The command used to review or improve the skills available to a character. |
| recall | The command that returns a character to their hometown. |
| remort | Starting again at level 1 in a remort class after reaching the required level. |
| rent | A fee some MUDs charge to preserve equipment while a character is away. Dark Pawns has no rent; quit in a temple to keep equipment. |
| tank | The character currently taking the opponent's attacks in a group fight. |
| THAC0 | To-hit armor class zero, the combat statistic used to determine whether an attack hits. |
| vnum | Virtual number, the numeric identifier for a room, mob, or object. |
| WHOD | The Who daemon, a separate server listener for player-listing services. |
| zone | A numbered part of the world files, grouping related rooms and reset rules. |
